## [Cisco] GNS3 기반 라우터 및 스위치 기초 명령어 정리

네트워크를 가상 환경에서 실습하기 위한 GNS3 설정법부터 Cisco IOS 기본 모드, 인터페이스 활성화 및 이웃 장비 확인 프로토콜(CDP/LLDP) 정리 내용이다. 

---

## 1. GNS3 실습 환경 구축

### GNS3 개요 및 특징

GNS3는 복잡한 네트워크를 가상으로 설계·구성·시뮬레이션할 수 있는 네트워크 에뮬레이터이다.

* **실제 OS 구동:** Cisco IOS, Juniper, HP 등 실제 장비의 바이너리 이미지를 그대로 구동하므로 명령어와 동작 방식이 실제 장비와 100% 일치한다.
* **다양한 가상화 연동:** Cisco 장비뿐만 아니라 Docker 컨테이너, VirtualBox, VMware 기반 VM을 토폴로지에 손쉽게 연동할 수 있다.
* **외부 네트워크 바인딩:** PC의 실제 NIC(랜카드)와 바인딩하여 가상 네트워크와 외부 물리 네트워크 간 데이터 송수신이 가능하다.
* **패킷 분석:** Wireshark와 연동하여 가상 링크의 패킷을 실시간으로 캡처하고 분석할 수 있다.

### IOS 이미지 등록 절차

다운로드한 이미지 압축을 해제한 후 아래 경로로 등록을 진행한다.

1. **스위치(EthernetSwitch) 등록**
* 메뉴: `[Edit]` $\rightarrow$ `[Preferences]` $\rightarrow$ `[Dynamips]` $\rightarrow$ `[IOS Routers]` $\rightarrow$ `[New]`
* 압축해제한 이미지 선택 후 **This is an EthernetSwitch router** 항목 체크
* 메모리 설정 후 Slot 옵션은 기본값 유지
* **Idle-PC finder**를 실행해 CPU 점유율 방지 주소를 찾아 지정


2. **라우터(c7200) 등록**
* 메뉴: `[Edit]` $\rightarrow$ `[Preferences]` $\rightarrow$ `[Dynamips]` $\rightarrow$ `[IOS Routers]` $\rightarrow$ `[New]`
* 이미지 선택 후 메모리 할당
* 슬롯 설정: **Slot1 $\rightarrow$ PA-4+**, **Slot2 $\rightarrow$ PA-4E** 추가
* **Idle-PC finder** 버튼을 눌러 명령어 주소 지정

## 2. Cisco IOS 실행 모드 및 저장

Cisco 장비의 모드는 명령어 실행 권한에 따라 단계별로 구분된다.

| 모드 이름 | 프롬프트 형태 | 설명 | 진입/이탈 명령어 |
| --- | --- | --- | --- |
| **User Mode** | `Router>` | 장비 상태 조회만 가능 (상태 변경 불가) | 기본 상태 |
| **Privileged Mode** | `Router#` | 주요 설정 확인 및 관리자 작업 가능 | 진입: `enable`<br>

<br>나가기: `disable` |
| **Global Config Mode** | `Router(config)#` | 장비 전반에 영향을 주는 설정 변경 | 진입: `configure terminal`<br>

<br>복귀: `exit` 또는 `Ctrl + Z` |
| **Interface Config Mode** | `Router(config-if)#` | 특정 인터페이스 속성 변경 | 진입: `interface [인터페이스명]` |

### 설정 내용 저장

현재 설정 메모리(RAM)의 내용을 NVRAM에 저장하여 장비 재부팅 후에도 유지되도록 설정한다.

```text
Router# copy running-config startup-config

```

## 3. 라우터 연결 및 인터페이스 활성화

라우터의 인터페이스는 기본적으로 **Shutdown(비활성화)** 상태로 설정되어 있으므로, 물리 케이블을 연결하더라도 반드시 활성화 작업을 진행해야 통신이 가능하다.

### 라우터 3대 연결 구조

* **R1 - R2**: `Ethernet2/0` 으로 연결
* **R2 - R3**: `Ethernet2/1` 로 연결

### 라우터별 인터페이스 활성화 명령어

**R1 설정**

```text
R1# configure terminal
R1(config)# interface ethernet2/0
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# exit
R1# show interface ethernet2/0

```

**R2 설정**

```text
R2# configure terminal
R2(config)# interface ethernet2/0
R2(config-if)# no shutdown
R2(config-if)# exit

R2(config)# interface ethernet2/1
R2(config-if)# no shutdown
R2(config-if)# exit
R2(config)# exit
R2# show interface ethernet2/0
R2# show interface ethernet2/1

```

**R3 설정**

```text
R3# configure terminal
R3(config)# interface ethernet2/1
R3(config-if)# no shutdown
R3(config-if)# exit
R3(config)# exit
R3# show interface ethernet2/1

```

## 4. 이웃 장비 탐색 프로토콜 (CDP / LLDP)

### CDP (Cisco Discovery Protocol)

Cisco 전유 프로토콜로, 물리적으로 직접 연결된 Cisco 장비들의 인접 정보(디바이스 ID, 연결 포트, 플랫폼 등)를 탐색할 수 있다.

* **인접 장비 확인**
```text
R1# show cdp neighbors

```


```text
Capability Codes: R - Router, T - Trans Bridge, B - Source Route Bridge
                  S - Switch, H - Host, I - IGMP, r - Repeater

Device ID        Local Intrfce     Holdtme    Capability  Platform  Port ID
R2               Eth 2/0            173           R       7206VXR   Eth 2/0

```


* **CDP 트래픽 통계 확인**
```text
R1# show cdp traffic

```



### LLDP (Link Layer Discovery Protocol)

Vendor-neutral 표준 이웃 탐색 프로토콜이다. 기본적으로 비활성화되어 있는 경우가 많아 수동으로 활성화해야 한다.

* **LLDP 활성화**
```text
Router(config)# lldp run

```


* **확인 명령어**: `show lldp neighbors`


>⚠️ 일부 IOS 이미지(특히 GNS3에서 흔히 쓰는 c7200, c3725 등 구형 라우터 이미지)는 LLDP를 지원하지 않을 수 있다. 이 경우 CDP로 대체하거나, LLDP를 지원하는 스위치 이미지(IOSvL2 등)로 실습해야 한다.

## 5. 라우터 IP 할당 및 확인

라우터의 각 인터페이스는 서로 다른 방송 구역(Subnet)을 형성한다. 따라서 동일한 링크로 연결된 라우터의 인터페이스끼리는 같은 서브넷 대역의 IP를 부여해야 한다.

### IP 할당 과정

```text
Router# configure terminal
Router(config)# interface ethernet2/0
Router(config-if)# ip address 192.168.1.1 255.255.255.0
Router(config-if)# no shutdown

```

### IP 할당 상태 간편 확인

```text
Router# show ip interface brief

```
