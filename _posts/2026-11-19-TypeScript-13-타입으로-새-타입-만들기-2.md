## 개요

앞 글에서 인덱스 접근과 매핑된 타입으로 객체 타입을 변형했다. 이번에는 타입에 따라 다른 결과를 선택하는 조건부 타입과 타입을 추출하는 `infer`를 살펴본다.

## 조건부 타입

조건부 타입은 `조건 ? 참일 때 타입 : 거짓일 때 타입` 형태다.

```ts
type Label<T> = T extends number ? "숫자" : "그 외";

type A = Label<number>; // "숫자"
type B = Label<string>; // "그 외"
```

`T extends number`는 `T`를 `number`에 할당할 수 있는지 확인한다. 값이 아니라 타입을 기준으로 결과 타입을 선택한다.

## 유니온에서 타입 걸러내기

다음 타입은 유니온에서 지정한 타입을 제거한다.

```ts
type MyExclude<T, U> = T extends U ? never : T;

type Remaining = MyExclude<"a" | "b" | "c", "a">; // "b" | "c"
```

이 형태의 조건부 타입은 `T`가 유니온이면 각 구성원에 따로 적용된다. `"a"`는 `never`가 되어 결과에서 사라지고 나머지가 남는다. 내장 `Exclude`의 기본 원리다.

## infer로 타입 추출하기

`infer`는 조건부 타입 안에서 **모양을 맞춰 보고, 그 안의 특정 자리에 있는 타입을 꺼내 오는** 문법이다. `extends` 오른쪽에 원하는 모양을 쓰고, 꺼내고 싶은 자리에 `infer 이름`을 넣는다. `infer`는 문법이고, 뒤의 이름은 직접 짓는다.

배열 요소의 타입을 꺼내 보자.

```ts
type ElementOf<T> = T extends readonly (infer Item)[] ? Item : never;

type A = ElementOf<string[]>; // string
type B = ElementOf<readonly number[]>; // number
type C = ElementOf<boolean>; // never
```

`readonly (infer Item)[]`는 "`???[]` 모양"이라는 틀이고, `infer Item`은 그 틀에 뚫린 빈칸에 `Item`이라는 이름을 붙인 것이다. `ElementOf<string[]>`는 다음 순서로 계산된다.

1. `T`에 `string[]`이 들어온다.
2. `string[]`이 `???[]` 모양에 맞는지 확인한다. 맞는다.
3. 모양을 맞춰 보면 빈칸 자리에 `string`이 있다. 따라서 `Item`은 `string`이 된다.
4. 조건이 참이므로 `?` 뒤의 `Item`, 즉 `string`을 반환한다.

`ElementOf<boolean>`은 2단계에서 `boolean`이 배열 모양이 아니므로 조건이 거짓이 되고 `never`를 반환한다. 이때는 빈칸이 채워지지 않으므로 `Item`을 쓸 수 없다. 그래서 `infer`로 붙인 이름은 참일 때의 결과(`?` 뒤)에서만 사용할 수 있다.

값에서 쓰는 구조 분해 할당과 생각하는 방식이 같다.

```ts
// 값: 배열 모양에 맞춰 첫 번째 칸을 first라는 이름으로 꺼낸다
const [first] = [10, 20]; // first는 10

// 타입: 배열 모양에 맞춰 요소 자리를 Item이라는 이름으로 꺼낸다
type X = string[] extends (infer Item)[] ? Item : never; // string
```

빈칸을 다른 자리에 두면 다른 타입을 꺼낼 수 있다. 다음 타입은 함수의 반환 타입 자리에 빈칸을 둔다.

```ts
type ReturnOf<T> = T extends (...args: any[]) => infer Result ? Result : never;

type Greeting = ReturnOf<() => string>; // string
```

틀은 "인자는 무엇이든 받고 `???`를 반환하는 함수" 모양이다. `() => string`을 이 틀에 맞추면 반환 타입 자리에 `string`이 있으므로 `Result`는 `string`이 된다.

같은 방식으로 `Promise` 안의 타입도 꺼낼 수 있다.

```ts
type Unwrap<T> = T extends Promise<infer Value> ? Value : T;

type D = Unwrap<Promise<string>>; // string
type E = Unwrap<number>; // number
```

`Promise<string>`은 `Promise<???>` 모양에 맞으므로 `Value`인 `string`을 반환한다. `number`는 모양이 맞지 않으므로 거짓일 때의 결과인 `T`, 즉 `number`를 그대로 반환한다.

실제 코드에서는 직접 만들지 않고 내장 유틸리티 타입을 사용할 수 있다. 함수의 반환 타입은 `ReturnType`, `Promise` 안의 타입은 `Awaited`로 얻는다.

## 정리

조건부 타입은 타입 관계에 따라 다른 타입을 선택한다. `infer`를 함께 사용하면 배열 요소나 함수 반환 타입처럼 구조 안에 들어 있는 타입을 추출할 수 있다.
