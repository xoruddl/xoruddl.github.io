# 도커 용어
**Docker**: 애플리케이션 실행 환경을 image와 container로 표준화하는 도구와 생태계
**Docker Engine**: image build, container run, network, volume을 실제로 처리하는 Docker 실행 엔진
**Image**: container를 만들기 위한 읽기 중심 실행 패키지 (붕어빵 틀)
**Container**: image에서 시작된 실행 중인 process와 격리된 실행 환경 (붕어빵)
**Registry**: image를 저장하고 내려받는 저장소 (Docker Hub)
**Dockerfile**: image를 만들기 위한 instruction 파일
