## 컨테이너 실행
```
# 컨테이너 실행
docker run -d --name first-container -p 18080:80 nginx:latest
# 컨테이너 확인
docker ps --filter name=first-container
```

## 컨테이너 중지 및 삭제
```
# 컨테이너 중지
docker stop first-container
# 컨테이너 삭제
docker rm first-container

```
![](https://velog.velcdn.com/images/eta_kyung/post/d0d80ec8-f6ee-4769-a597-7ee98a43dd6f/image.png)
삭제가 완료된 후 해당 컨테이너가 없는 모습이다.
